# CNCVerse CloudStream Extension — Debloated Fork

**Personal fork for personal use. No warranty or guarantee provided.**

This is a **debloated** version of [CNCVerse-Cloud-Stream-Extension](https://github.com/NivinCNC/CNCVerse-Cloud-Stream-Extension) by **NivinCNC**, built from the last known GPLv3-licensed source.

I do **not** update this repository frequently. **Please use the [official version](https://github.com/NivinCNC/CNCVerse-Cloud-Stream-Extension) to support the original developers.**

### Changes from official

- Removed forced external browser ad redirects
- Removed Telegram promotion popups
- Removed unused hidden ad URL BuildConfig fields
- Removed subscription/ads popup
- Kept provider scraping/playback logic unchanged
